# 真人 PK 高光导出：第一版

## 本机运行

需要 Node.js 22+。在项目根目录运行：

```powershell
npm install
Copy-Item .env.example .env
npm start
```

访问 `http://localhost:8000/web_dance/`，选择真人 PK。在游戏右上角展开「我的高光」，勾选录制，再开始游戏。结束后自动上传、剪辑，领取面板展示二维码、进度和领取链接。默认不录制，不采集麦克风。

本机模式无需阿里云；原始录像、任务和成片保存在 `.highlight-data/`（已忽略 Git）。FFmpeg 默认由 `ffmpeg-static` 安装；如果安装环境无法下载该二进制，可配置 `FFMPEG_PATH` 指向已安装的 FFmpeg。

原有 Python 静态服务器仍可运行游戏，但不能提供高光 API。高光功能需使用 `npm start`。

## 手机扫码与部署

`localhost` 二维码只能在当前电脑打开，手机需要能访问的地址。部署时配置：

```dotenv
HOST=0.0.0.0
PORT=8000
PUBLIC_BASE_URL=https://dance.example.com
DEVICE_TOKEN=替换为足够长的随机密钥
```

使用 HTTPS 反向代理指向服务，并从 `PUBLIC_BASE_URL` 打开游戏页面。摄像头需要安全上下文；不要把普通局域网 HTTP 页面当作正式摄像头入口。反向代理需允许至少 512 MB 上传、足够的超时时间；不要缓存 `/api/`。在设备设置中填写 `DEVICE_TOKEN`，只保存在该标签页会话存储中。手机领取页无需设备密钥。

单实例服务，持久磁盘必需。不要对同一任务目录运行多个服务实例。当前任务队列一次转码一条，最多允许 20 条未完成任务；生产部署需根据机器规格配置进程内存、CPU 和磁盘配额。

## 阿里云 OSS

```dotenv
STORAGE_MODE=oss
OSS_REGION=oss-cn-hangzhou
OSS_BUCKET=你的私有存储桶
OSS_ACCESS_KEY_ID=服务端凭证
OSS_ACCESS_KEY_SECRET=服务端凭证
OSS_PUBLIC_DOMAIN=https://media.example.com
```

- Bucket 必须为私有。长期密钥仅在服务端环境变量中，前端只获得针对本局 `source` 对象的短时 PUT 签名。
- RAM 权限限制在该 Bucket 的 `highlights/*` 路径：读取、写入、删除对象；使用临时服务端凭证时自行管理刷新，不能长期使用过期 STS Token。
- 将媒体自定义域名绑定 Bucket 并配置 HTTPS，保证手机可在线播放。上传通过 OSS 原生域名；播放通过自定义域名签名。
- Bucket CORS：允许游戏页面的精确 Origin，允许 `PUT`，允许 `Content-Type` 请求头。按实际 SDK/浏览器预检添加所需配置，避免无条件开放来源。
- 上传结束由后台检查对象存在及大小，处理时再按 512 MB 上限读取；成片统一 H.264/AAC MP4，9:16 竖屏 1080×1920/60fps、faststart，H.264 CRF 18。
- 后台负责清理：成片保存 7 天，成功任务的原始录像创建 1 天后删除。失败任务原片保留至任务过期以便重试。建议再配置 OSS 生命周期兜底：`highlights/` 前缀 8 天后过期，且清理未完成分片。
- `STORAGE_MODE` 和 Bucket 不能在有未完成任务时直接切换；需要等待处理完毕或另用任务目录。

第一版没有自动创建 Bucket、域名、HTTPS、RAM 权限；上述配置必须在自己的账号完成。未配置真实 OSS 时仅验证本地存储链路。

## 录制与选段

- 专用 9:16 竖屏 1080×1920 画布合成：3D 舞台作背景（cover 裁剪铺满），真人画面占上半部主体，顶部钩子文案、底部分数/连击/判定短语，真人沿用当前页面的镜像展示并完整包含画面。
- 音乐从 AudioEngine 分支直接录入，不录麦克风。
- 倒计时结束启动录制；评分样本使用相对录像的时间，避免把倒计时计入高光。
- 每秒采样匹配度、置信度、连击和判定。选择最高表现的连续 28 秒，再追加 2 秒成绩卡；短歌曲保留全段。第一版不做音乐小节对齐。
- 最长录制 10 分钟、单文件 512 MB；浏览器录制时暂存内存，结束后将待上传 Blob 保存到 IndexedDB，再上传。刷新后恢复领取记录，可手动重试待上传视频。
- 同时最多保留 3 条待上传录像；录制期间请保持页面前台。下一局可以开始，上一局继续上传。关页时浏览器会尝试提示，但不能保证退出时仍完成上传。
- 不支持录制中的断点恢复。网络失败重试会重新上传整个文件，尚未实现 OSS 分片续传。
- 不支持在游戏中途暂停录像或后台标签页持续录制；手动停止/切换模式会取消本局高光。

## 接口与权限

| 接口 | 用途 | 凭证 |
|---|---|---|
| POST `/api/highlights` | 创建本局任务 | `X-Device-Token` |
| POST `/:id/upload-url` | 获取短时上传地址 | `X-Owner-Token` |
| PUT `/:id/source` | 本地模式上传 | `X-Owner-Token` |
| PUT `/:id/card` | 上传成绩卡 PNG | `X-Owner-Token` |
| POST `/:id/complete` | 提交时长、评分采样和成绩，幂等 | `X-Owner-Token` |
| POST `/:id/retry` | 失败转码重试，最多 3 次 | `X-Owner-Token` |
| DELETE `/:id` | 删除并立即禁用访问 | `X-Owner-Token` |
| GET `/:id`、`/:id/qr` | 状态、领取二维码 | 随机领取码 |
| GET `/:id/media`、`/:id/poster` | 成片、封面 | 随机领取码 |

除创建接口外，上表缩写接口均位于 `/api/highlights` 下。领取码与管理令牌分别使用 192 位随机数；公开接口不返回管理令牌。领取页面地址不含 OSS 签名。播放请求再签发最长 5 分钟的 OSS 地址；已发出的签名在有效期内可能继续有效，文件清理完成后失效。领取码属于持有者访问凭证，不等同于用户身份认证。

删除只能在记录该任务的游戏设备操作。处理中的任务须等待完成/失败再删除。原始录像不提供公开访问。部署不应公开整个项目根目录。
