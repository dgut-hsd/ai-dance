判定点簿

    pose 判定点 选中 弱拍 / 强拍 / 播放头

    判定轨道预览 · 玩家右下角看到的就是这张卡片(所见即所得)

    谱面编辑器 · 3 分钟上手

    一句话:音乐是尺子,参考序列是标准答案,谱面是"第几秒考哪个姿势"; 右下角那张卡片就是把这道题提前 2.4 秒摆给玩家看 —— 剪影画的就是参考序列那一帧的姿势。

    ① 先来一支舞

    • 新建:点「舞曲文件夹」选一个含 .fbx(+音频)的文件夹 → FBX 被采集成 30fps 参考序列, 并自动铺「每 2 拍」一个判定点。
    • 改谱:用「曲子」下拉挑歌单里已有的舞曲,直接编辑它的判定点。

    ② 摆判定点(时间轴下半条)

    • 点空白 = 加一个判定点;拖动 = 改时刻;右键或列表里的 ✕ = 删;点 = 选中。
    • 时间轴上半条拖动 = 移动播放头;选中判定点会自动把播放头跳过去,左栏姿势预览随之更新。
    • 「BPM / 偏移s」决定拍在哪(先把偏移对到鼓点);「LPB」= 每拍的网格数(1=整拍,4=十六分音,8=三十二分音…),数字越大能摆的判定点越细;「吸附节拍」开着时判定点会吸到最近的网格线(拍/LPB 细分)。
    • 「每拍 / 每2拍 / 每4拍」= 按拍栅格重铺一遍(会覆盖现有判定点);「清空」全删。

    ③ 边听边看,然后保存

    • 点「播放 ▶」:波形 + 播放头 + 下方判定轨道预览会跟着走 —— 玩家看到的卡片就是它;开着「判定点音效」时经过每个判定点会"嗒"一声，方便对音(强拍音更低更长)。
    • 选中判定点后,左栏属性区可改:时刻 / 类型 / 难度 / 判定窗 / 动作名 / 只算哪几根骨头。
    • 「保存到歌单」→ 写 songs/<ID>/ 并刷新歌单;回游戏页刷新即可挑战(卡片就用这份谱面)。

    名词对照

    判定点(pose)
    第 t 秒要求玩家做的姿势。卡片上飘过的剪影 = 参考序列里该时刻的那一帧。
    参考序列(frames)
    逐帧姿势,判分时的标准答案;FBX / 视频动捕 / 摄像头三种来源。
    判定窗(±0.25s)
    玩家在这段时间内做到都算命中,越宽越宽容。
    骨骼子集(局部)
    只拿这几根骨头比对 → "只考手部"这类局部动作。
    动作名(note.id)
    给这个判定点起的名字,存在谱面里(便于自己认谱);当前卡片不显示文字。
    难度
    该判定点的分值权重(1~10)。

    想要选曲卡那种 3D 白影剪影?

    判定轨道的剪影默认是 2D 剪影;跑一次 node tools/lane-silhouettes.mjs 会按判定点逐张预渲染 3D 白影 + 清单,游戏与这里的预览都会自动换成它(没生成的舞曲自动退回 2D)。

    保存需要 Node 服务(npm start → 用 http 打开本页);纯静态服务器只能看不能存。
