谱面编辑器 跟着 4 步走,傻瓜式操作

谱面 = 一张「在哪些拍子上判分」的清单。下面按 ①→②→③→④ 走一遍,就能给一首歌做出谱面。

1放一首歌

选一个音频文件(mp3 / wav)。选好后下面会画出波形——波形高的地方就是鼓点/重音。

还没选音频

2告诉编辑器「拍子」在哪

二选一:方式 A 选一个 timing.json(用 detect_beats.py 生成的最准);没有的话用 方式 B 边放歌边跟着节奏点「打拍」。

方式 B: 连点 4 次以上自动算出 BPM

3决定「哪里判分」(音符)

每个绿点 = 一个音符 = 一个判分点。最省事:点「一键铺满下拍」自动在每个小节的第 1 拍放一个;也可以点时间轴手动加/删。

已放 0 个音符

4导出谱面

得到 chart.json。把它和 timing.json、音频一起合并进舞蹈序列,挑战模式就会在你放的音符上判分。

时间轴 0.0s / 0.0s

金色竖线 = 下拍(每小节第 1 拍) 灰竖线 = 普通拍 绿点 = 音符(判分点) 红线 = 播放位置 点击时间轴 = 在最近的一拍上放/删音符
